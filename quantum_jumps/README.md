# PHYS 137T Quantum Jumps

An interactive demonstration of quantum jumps and Rabi oscillation in a
single trapped Hg⁺ ion.

## Run locally

```sh
npm install
npm run dev
```

## Live demo

https://mgrau.github.io/phys137t-demos/quantum_jumps/

The live page can be embedded in Canvas with an iframe or added as an external
URL/module item.
