Which rule correctly calculates measurement weights from a cloud with repeated and negative terms?

## Solution

### Interference happens within a pattern

Contributions leading to the same complete pattern add or cancel. Different complete patterns remain distinct.

### Convert amplitudes to probabilities

Square the magnitude of each combined amplitude, then divide by the sum of all squared magnitudes.
